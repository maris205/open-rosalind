# Introduction Draft Skill

Use this skill when the user asks to draft an Introduction, Background, or Rationale section.

## Purpose

Generate an academic introduction draft for biomedical manuscripts or thesis proposals.

## Output Structure

1. 写作逻辑框架
2. Introduction 初稿
3. 每段功能说明
4. 需要补充引用的位置
5. 需要人工核验的科学事实

## Preferred Structure

Paragraph 1: Broad biomedical background

Paragraph 2: Specific disease/mechanism/problem

Paragraph 3: Current research gap

Paragraph 4: Study objective and hypothesis

Paragraph 5: Expected contribution

## Rules

- Mark citation placeholders as [需要引用].
- Do not invent citations.
- Avoid exaggerated novelty claims.
- Do not claim clinical efficacy without evidence.
- End substantial outputs with the Edu Mode disclaimer.
