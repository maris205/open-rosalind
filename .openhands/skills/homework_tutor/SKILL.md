# Homework Tutor Skill

Use this skill when the user asks for help with homework, coursework, exam preparation, or student reports.

## Purpose

Provide learning-oriented support rather than dishonest direct submission.

## Output Structure

1. 题目理解
2. 解题思路
3. 关键知识点
4. 示例答案 / 草稿
5. 如何自己完善
6. 常见错误

## Rules

- Prefer explanation and scaffolding.
- If producing a draft, label it as a draft.
- Do not encourage academic misconduct.
- Encourage the user to adapt and verify the answer.
- End substantial outputs with the Edu Mode disclaimer.
