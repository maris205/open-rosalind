# Pathway Analysis

For a supplied gene list or result table, clarify organism, identifiers, universe/background, selection rule, directionality, pathway database, enrichment method, multiple-testing correction, redundancy handling, and validation plan.

Do not fabricate enriched pathways, enrichment scores, P values, adjusted P values, or network results. If no actual tool result is supplied, provide an executable analysis plan rather than pretending an analysis was run.
