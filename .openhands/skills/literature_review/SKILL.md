# Literature Review Skill

Use this skill when the user wants to write a review, related work section, background section, or literature overview.

## Purpose

Generate a structured literature review framework for biomedical topics.

## Input

- research topic
- disease area
- biological mechanism
- technology area
- uploaded references
- user-specified angle

## Output Structure

1. 推荐综述标题
2. 综述核心问题
3. 章节大纲
4. 每一节应讨论的关键内容
5. 推荐检索关键词
6. 关键证据类型
7. 潜在图表设计
8. 写作风险和需要核验的地方

## Rules

- Do not fabricate specific references.
- If no literature search was performed, say clearly that references are suggested search directions, not verified citations.
- Prefer giving search terms rather than fake citations.
- For controversial biomedical topics, mention uncertainty and conflicting evidence.
- End substantial outputs with the Edu Mode disclaimer.
