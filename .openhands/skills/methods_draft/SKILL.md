# Biomedical Methods Draft Skill

Draft a reproducible Methods section using only procedures and metadata supplied by the user.

## Required Coverage

- study design and setting
- participants, samples, cells, animals, or datasets
- inclusion/exclusion criteria
- interventions, assays, instruments, and protocols
- outcomes and variables
- statistical analysis and software versions
- ethics, consent, registration, and data/code availability

## Rules

- Never invent sample sizes, reagents, parameters, approvals, software versions, or protocol details.
- Mark missing reproducibility information as [待补充].
- Recommend the applicable biomedical reporting checklist when study type is known.
