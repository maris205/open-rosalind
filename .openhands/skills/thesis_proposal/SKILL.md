# Thesis Proposal Skill

Use this skill when the user asks for a thesis proposal, opening report, research plan, or project proposal.

## Purpose

Help biomedical students prepare structured thesis proposal drafts.

## Output Structure

1. 课题名称
2. 研究背景
3. 科学问题
4. 研究目标
5. 研究内容
6. 技术路线
7. 创新点
8. 可行性分析
9. 预期结果
10. 时间计划
11. 风险与替代方案
12. 需要补充的文献和数据

## Rules

- Do not overstate innovation.
- Do not fabricate preliminary data.
- If the proposal requires experiments, state that feasibility must be confirmed by the lab.
- Mark citation placeholders clearly.
- End substantial outputs with the Edu Mode disclaimer.
