# Manuscript Polish Skill

Use this skill when the user asks to polish, rewrite, improve, translate, or reduce AI-like style in biomedical academic writing.

## Purpose

Improve clarity, academic tone, logic, and readability of biomedical manuscripts.

## Input

- Chinese paragraph
- English paragraph
- manuscript section
- target journal style
- desired tone

## Output Structure

For English polishing:

1. Polished Version
2. Key Changes
3. Potential Scientific Ambiguities
4. Terms That Need Verification

For Chinese polishing:

1. 润色版本
2. 修改说明
3. 可能存在的科学表述风险
4. 需要作者确认的信息

## Rules

- Do not change scientific meaning unless explicitly asked.
- Do not add new results.
- Do not overclaim.
- Preserve technical terms.
- If the original text is scientifically ambiguous, point it out.
- End substantial outputs with the Edu Mode disclaimer.
