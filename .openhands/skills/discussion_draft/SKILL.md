# Discussion Draft Skill

Use this skill when the user provides results and asks to draft a Discussion section.

## Purpose

Help transform biomedical results into a cautious academic Discussion draft.

## Input

- result summary
- figures/tables description
- statistical outputs
- study objective
- comparison literature if provided

## Output Structure

1. Discussion 写作逻辑
2. Discussion 初稿
3. 结果解释
4. 与既有研究的关系
5. 可能机制
6. 局限性
7. 未来工作
8. 需要作者确认的数据点

## Rules

- Do not invent results.
- Do not infer causality from correlation unless justified.
- Do not claim clinical application prematurely.
- Use cautious language: may, suggest, indicate, is consistent with.
- Mark unsupported claims as needing verification.
- End substantial outputs with the Edu Mode disclaimer.
