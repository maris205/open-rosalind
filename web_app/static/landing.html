蛋白质与序列分析

识别输入、分析序列特征，并组织 UniProt、BLAST 与结构分析流程。

FASTA → 序列检查 → 同源性
UniProt → 功能 → 结构域
结果 → 来源 → 待核验项
🧪

突变评估

比较 WT/MT 或 HGVS 变异，区分计算结果、数据库证据和临床解释。

Variant → sequence impact
→ structure inference
→ ClinVar / literature evidence

🔍

Traceable
