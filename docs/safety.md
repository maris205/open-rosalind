# Safety Notes

Open-Rosalind Edu 的核心安全原则是学习辅助、证据透明和人工核验。

## 内容安全边界

- 不提供临床诊断或治疗建议。
- 不伪造 DOI、PMID、实验数据、统计结果、样本量、作者或参考文献。
- 不声称生成内容已经经过实验验证。
- 不替代原始文献阅读、统计分析或导师审阅。
- 不鼓励学术不端。

## 工程权限建议

第一版作为 OpenHands Web GUI 中的 Edu Agent 使用时，建议仅面向开发者内测。若对学生开放，需要限制危险能力：

- 限制任意 shell command。
- 限制外部网络下载脚本。
- 限制读取宿主机敏感目录。
- 禁止自动 git push。
- 禁止自动发布内容。
- 禁止自动提交作业或论文。
- 禁止自动访问用户私人账号。

## 允许能力

- 读取用户上传的论文或文本。
- 解析 PDF。
- 生成 Markdown。
- 生成 DOCX。
- 调用受控文献搜索接口。
- 调用受控导出脚本。

## 输出要求

所有较长输出必须附带 Edu Mode disclaimer，并在生物医学 claim 处提醒用户人工核验。
