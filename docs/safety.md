# Safety Notes

Open-Rosalind Edu 的核心安全原则是学习辅助、证据透明和人工核验。

## 内容安全边界

- 不提供临床诊断或治疗建议。
- 不伪造 DOI、PMID、实验数据、统计结果、样本量、作者或参考文献。
- 不声称生成内容已经经过实验验证。
- 不替代原始文献阅读、统计分析或导师审阅。
- 不鼓励学术不端。

## 工程权限建议

Edu Agent 的 OpenHands 执行采用按任务启动的临时容器：

- 每个容器只挂载当前用户的当前项目目录到 `/workspace/project`；
- 不挂载其他用户、其他项目或整个宿主工作区；
- 每个容器使用随机、一次性的 Agent Server session key 和 secret key；
- 任务结束后容器自动停止并删除；
- Worker 启动时会清理异常中断遗留的隔离容器；
- 常驻的共享 OpenHands Agent Server 在隔离模式下保持禁用。

桌面内测版默认不要求 Docker，并提供经过用户逐次确认的本机 Python 执行。该模式与容器执行的安全边界不同：

- 代码在客户端当前操作系统用户权限下运行；
- 任务工作目录、输出和审计记录位于客户端应用数据目录；
- 本机模式不提供文件系统、网络或内存硬隔离；
- 界面必须在执行前明确提示上述权限，不得沿用“无网络 Docker 沙箱”的描述；
- 不可信代码、需要复现的分析和对外开放场景仍应使用 Docker 模式。

若对学生或外部用户开放，仍需限制危险能力：

- 限制任意 shell command。
- 限制外部网络下载脚本。
- 限制读取宿主机敏感目录。
- 禁止自动 git push。
- 禁止自动发布内容。
- 禁止自动提交作业或论文。
- 禁止自动访问用户私人账号。

## 允许能力

- 读取用户上传的论文或文本。
- 解析 PDF。
- 生成 Markdown。
- 生成 DOCX。
- 调用受控文献搜索接口。
- 调用受控导出脚本。

## 输出要求

所有较长输出必须附带 Edu Mode disclaimer，并在生物医学 claim 处提醒用户人工核验。
