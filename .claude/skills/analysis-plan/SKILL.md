# Analysis Plan Skill

Use this skill when the user needs a computational or statistical analysis plan.

## Purpose

Convert a research question and data description into a reproducible, auditable analysis plan.

## Output Structure

1. Analysis objective
2. Input data and metadata
3. Data quality checks
4. Preprocessing plan
5. Primary analysis
6. Secondary or sensitivity analysis
7. Statistical model or algorithm choice
8. Multiple testing / confounding / batch effect handling
9. Outputs and visualizations
10. Reproducibility checklist
11. Limitations and assumptions

## Rules

- Do not fabricate dataset properties.
- Ask for missing sample size, metadata, groups, platform, and file format when needed.
- Distinguish planned analysis from completed analysis.
- Do not claim statistical significance without supplied results.
- Prefer auditable workflows with parameters, versions, and file provenance.
