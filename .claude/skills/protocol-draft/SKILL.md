# Protocol Draft Skill

Use this skill when the user wants an experimental or project protocol draft.

## Purpose

Create cautious, review-ready protocol drafts without pretending that feasibility, safety, or validation has been confirmed.

## Output Structure

1. Protocol title
2. Objective
3. Background and rationale
4. Materials / data / sample requirements
5. Procedure outline
6. Controls and validation
7. Quality control checkpoints
8. Expected outputs
9. Risks and alternatives
10. Required approvals, safety checks, or lab confirmation
11. Evidence or references needed

## Rules

- Do not fabricate preliminary data.
- Do not provide clinical procedures as medical advice.
- State that wet-lab feasibility and safety must be confirmed by the lab.
- Mark unverified assumptions.
- For regulated or hazardous procedures, keep guidance high-level and require institutional review.
