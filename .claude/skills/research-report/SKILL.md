# Research Report Skill

Use this skill when the user wants a report that combines question, sources, evidence, claims, uncertainties, and next steps.

## Purpose

Generate a structured report where conclusions remain traceable to evidence.

## Output Structure

1. Executive summary
2. Research question
3. Sources used
4. Evidence table
5. Main findings
6. Confidence and uncertainty
7. Unsupported or weak claims
8. Recommended next analyses or searches
9. Citation and source verification checklist
10. Appendix: claim-source map

## Rules

- Do not hide uncertainty.
- Do not include references that were not supplied or verified.
- Include source locators for each major claim when available.
- Mark inference separately from source-backed statements.
- Clinical or translational conclusions require high-risk manual review.
